# Checkout Redesign - A/B Test Analysis

**Did a streamlined checkout flow actually lift purchase conversion? A full experiment readout: significance testing, confidence intervals, validity checks, power, and segment-level effects — ending in a ship/no-ship call.**

## The experiment

A 14-day randomized test on **60,000 users**, split ~50/50, exposed to either the existing checkout (**control**) or a streamlined redesign (**treatment**). Randomization unit: the user. Primary metric: **purchase conversion rate**. Secondary: **revenue per user (RPU)** and **average order value (AOV)**.

## Result

| | |
|---|---|
| Control conversion | 12.82% |
| Treatment conversion | 14.77% |
| **Absolute lift** | **+1.94pp** (95% CI [1.39, 2.49]) |
| **Relative lift** | **+15.1%** |
| Significance | z = 6.9, **p ≈ 5.4 × 10⁻¹²** |
| Revenue per user | **+14.9%** (p ≈ 5 × 10⁻⁹) |
| **Decision** | ✅ **Ship** |

### What the analysis actually found

- **The lift is real and large** — a +15.1% relative gain in conversion, with a confidence interval that comfortably excludes zero, and the effect carries through to revenue per user with no drop in average order value.
- **The win is almost entirely mobile.** Mobile users gained **+2.78pp (highly significant)**; **desktop was flat at +0.60pp and *not* statistically significant (p = 0.22)**. So the redesign helps small screens — a desktop rollout would warrant its own test rather than assuming the effect generalizes.
- **The result is trustworthy:** the sample-ratio-mismatch (SRM) check passes (χ² test, p = 0.99), the observed effect exceeds the minimum detectable effect (0.77pp at 80% power), and conversion separates early and stays separated across the run (not a peeking artifact).

## Methods (implemented from first principles with scipy)

- **Two-proportion z-test** for the primary metric, with pooled standard error.
- **95% confidence intervals** on each rate and on the difference.
- **Sample-ratio-mismatch (SRM)** chi-square — the validity check most people skip.
- **Power / minimum detectable effect (MDE)** via normal approximation, plus achieved power.
- **Welch t-test** on revenue per user and AOV.
- **Segment / heterogeneous-effect analysis** by device and user type, with an explicit multiple-comparisons caution.
